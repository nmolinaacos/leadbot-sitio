# Sitio público de Leadbot

Páginas estáticas que pide Meta para la verificación del negocio y la App Review: inicio, política de privacidad, eliminación de datos y términos. Se publican con GitHub Pages desde la rama `main`.

Al cambiar `assets/landing.css` o `assets/landing.js`, sube el número `?v=` con que los carga `index.html`: GitHub Pages deja que el navegador guarde los archivos 10 minutos y, sin eso, alguien puede ver la página nueva con estilos viejos.
